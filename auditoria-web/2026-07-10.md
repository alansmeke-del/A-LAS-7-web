**Problemas encontrados:**
1. **(Seguridad, prioridad alta)** El JS embebido en `index.html` expone en
   texto plano, visible en "ver código fuente":
   - Un Bearer token de la API de MailerLite completo (línea ~395), con
     expiración codificada para ~año 2126 y `scopes: []` (sin restricción
     visible) — cualquiera puede copiarlo desde el navegador.
   - El secreto `X-ALAS7-Secret` (`alas7secret2026`, línea 393) usado para
     `/generate-promo` — al estar en el cliente, deja de funcionar como
     secreto real (cualquiera puede llamar al endpoint de generación de
     códigos promo directamente).
2. **(Bajo)** 3 enlaces muertos en el footer: los íconos de Instagram, X y
   LinkedIn (`aria-label="Instagram"`, `"X"`, `"LinkedIn"`) tienen
   `href="#"` sin URL real ni handler de JS — si un usuario hace clic, no pasa
   nada.
3. **(Bajo, observabilidad)** En `showPromo()`, si el fetch a `/generate-promo`
   falla, el `catch` no registra nada (sin `console.error`) y sustituye
   silenciosamente el código por el valor fijo `'ALAS7-2026'` para todos los
   visitantes. Si ese endpoint se cae en producción, nadie se enteraría por
   consola ni por ningún otro medio — simplemente todos verían el mismo código
   genérico.
4. **(Cosmético)** La constante `SESSION_KEY = 'vita_promo_seen'` conserva un
   nombre de una marca/proyecto anterior ("vita"), aunque el `CNAME` y todo el
   copy visible ya están correctamente en `alas7.com`/A LAS 7.
