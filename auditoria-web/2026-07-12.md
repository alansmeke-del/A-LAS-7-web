⚠️ **Hallazgo crítico de seguridad (nuevo, no relacionado con lo anterior):**
el archivo `index.html` tiene **credenciales sensibles hardcodeadas en texto
plano, visibles a cualquiera que vea el código fuente de la página**:
- Línea 395: un JWT `Authorization: Bearer …` completo para la API de
  MailerLite. El campo `exp` del token decodifica a un timestamp ~año 2126,
  es decir, un token de vida prácticamente permanente.
- Línea 393: `SECRET = 'alas7secret2026'`, usado como header
  `X-ALAS7-Secret` para `/generate-promo` — al estar en el HTML público deja
  de funcionar como secreto (cualquiera puede llamar el endpoint de promo
  directamente, sin pasar por la página).

Ambos ya estaban en el repo desde el commit `cb6f7a9` (3-jul, "Cut over
index.html to the de-runtimed A LAS 7 redesign"), no es una regresión de hoy,
pero sigue siendo explotable ahora mismo: cualquier visitante puede abrir
"ver código fuente" y quedarse con el bearer token de MailerLite o generar
códigos promo a discreción. **No se tocó nada — solo se documenta.**
