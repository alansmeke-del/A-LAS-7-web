**Problemas encontrados:**
1. **Secretos expuestos en el JS del cliente (index.html líneas 393-395):** el Bearer token de MailerLite (JWT con `exp` ~año 2126, prácticamente permanente) y el secreto `X-ALAS7-Secret: alas7secret2026` están hardcodeados en texto plano y son visibles para cualquiera que abra "ver código fuente". Esto ya existía antes de hoy (no es una regresión de este commit), pero sigue siendo el hallazgo más serio de la revisión: con ese Bearer token cualquiera puede llamar directamente a la API de MailerLite fuera del flujo de la página.
2. **Fallback silencioso en el popup de promo (línea 511-513):** si `/generate-promo` falla o no responde, el catch no avisa al usuario — simplemente muestra el código fijo `ALAS7-2026` como si fuera válido. Si ese código no existe como promo code real en Stripe, el usuario ve un "descuento" que fallará al aplicarlo en checkout, sin ningún indicio de que hubo un error.
3. **Links muertos en redes sociales del footer:** Instagram, X y LinkedIn (líneas 321-323) apuntan a `href="#"` sin URL real — no llevan a ningún lado. Bajo impacto, probablemente intencional hasta tener esas cuentas, pero es un link roto de cara al usuario.
4. **Testimonios placeholder:** las 3 tarjetas de testimonios (líneas 264-278) siguen con el texto "Espacio reservado para un testimonio real" — no es un bug técnico, es contenido pendiente de reemplazar.

Sin hallazgos en: sintaxis del JS (`node --check` limpio sobre el script extraído), CNAME (dice `alas7.com`, correcto — no hay rastro de `vitanews` ni `alas7.mx`), ni referencias a dominios inexistentes.

**Recomendación:** (nada de esto se corrigió — solo se documenta)
- Prioridad alta: mover el Bearer token de MailerLite y el secreto de promo fuera del JS del cliente (el proxy de Railway ya existe para esto — el token no debería viajar al navegador).
- Prioridad media: que el catch de `/generate-promo` muestre un mensaje de error real en vez de simular un código válido.
- Prioridad baja: completar los links de redes sociales o quitarlos del footer mientras no existan cuentas reales.
- Verificar manualmente (fuera de este entorno) que `alas7.com`, el link de Stripe y `/generate-promo` respondan 200 — este auditor no tuvo salida de red para confirmarlo hoy.
