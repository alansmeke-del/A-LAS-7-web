**Problemas encontrados:**
1. **[Crítico — persiste desde al menos el 2026-07-30, sin corregir]** Bearer
   token JWT completo de MailerLite hardcodeado en el JS del cliente
   (`index.html:395`, `const BEARER = 'eyJ0eXAi...'`), visible para cualquiera
   con "Ver código fuente". El `exp` del token es prácticamente infinito (~año
   2126). Cualquiera puede copiar este token y llamar directamente a la API de
   MailerLite sin pasar por el proxy de Railway. Este es el tercer día
   consecutivo que este auditor detecta la misma credencial expuesta en
   producción sin cambios.
2. **[Bajo — persiste]** El secreto `X-ALAS7-Secret` (`alas7secret2026`,
   `index.html:393`) para `/generate-promo` también está hardcodeado en el JS
   del cliente — es, por definición, un secreto de front-end no secreto.
3. **[Bajo — persiste]** Tres links `href="#"` sin handler ni URL real en el
   footer: íconos de Instagram, X y LinkedIn (`index.html:321-323`). (Los demás
   `href="#"` del sitio —botones "Gratis"— sí están interceptados por JS para
   abrir el modal y no son un problema.)
4. **[Bajo — persiste]** Manejo de errores silencioso sin registro: los `catch`
   de `submitFree()` (`index.html:457`) y `showPromo()` (`index.html:511`)
   atrapan fallos de red/API sin ningún `console.error` ni telemetría. Si
   `/subscribe` o `/generate-promo` empiezan a fallar, no queda ningún rastro
   detectable desde el navegador o logs del servidor — en el caso de
   `/generate-promo`, todos los visitantes recibirían el mismo código fijo
   `ALAS7-2026` sin que nadie se entere.
5. **[Info]** Validación local: `node --check` sobre el `<script>` extraído de
   `index.html` no reportó errores de sintaxis. `CNAME` contiene correctamente
   `alas7.com` (no `vitanews` ni `alas7.mx`). No se encontraron referencias a
   dominios inexistentes ni URLs `http://` sin cifrar. Los assets locales
   referenciados (`assets/logo7-v2.png`, `aviso-de-privacidad.html`,
   `terminos.html`) existen en el repo.

**Recomendación:** (no corregido, solo diagnóstico)
- **Prioridad alta:** rotar de inmediato el Bearer token de MailerLite expuesto
  en `index.html:395` — ya lleva 3+ días expuesto en producción — y mover esa
  llamada al backend de Railway para que el front-end no maneje ninguna
  credencial embebida.
- Revisar también el patrón del secreto `X-ALAS7-Secret` fijo para
  `/generate-promo` (considerar rate limiting por IP o un token de un solo uso).
- Reemplazar o quitar los tres íconos sociales del footer sin URL real.
- Agregar `console.error` o un beacon de log al backend en los `catch` de
  `submitFree()` y `showPromo()` para detectar caídas de los endpoints sin
  depender de reportes de usuarios.
- Verificar manualmente desde fuera de este entorno que `https://alas7.com/`
  responde 200 OK, dado que este auditor no pudo confirmarlo por restricciones
  de red del sandbox.
