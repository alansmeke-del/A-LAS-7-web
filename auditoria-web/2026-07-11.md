**Problemas encontrados:**
1. **[Seguridad — alto] Secreto de API de MailerLite expuesto en el HTML público.**
   `index.html` línea 395 incluye en texto plano un Bearer token JWT completo
   (`const BEARER = 'eyJ0eXAi...'`) usado en el header `Authorization` de la
   llamada a `/subscribe` (línea 449). Decodificado, el token no tiene fecha de
   expiración útil (`exp` cae en el año 2126) y su campo `scopes` está vacío —
   en la convención de tokens personales de MailerLite, scopes vacíos suelen
   implicar acceso completo a la cuenta. Cualquier visitante puede copiar este
   token desde "ver código fuente" y usarlo para leer/exportar la lista de
   suscriptores, modificar grupos o abusar de la cuenta de MailerLite fuera del
   flujo de la landing. Esto es independiente de si el proxy Railway también
   valida algo — el token vive del lado del cliente sin protección.
2. **[Menor] Fallback silencioso de código promocional.** En `showPromo()`
   (línea 506-513), si `fetch(API + '/generate-promo')` falla o el JSON no trae
   `code`, el modal muestra el código fijo `'ALAS7-2026'` y prellena el link de
   Stripe con `?prefilled_promo_code=ALAS7-2026` sin avisar al usuario del
   error. Si ese código no existe (o ya no es válido) como Promotion Code en
   Stripe, el usuario ve un cupón "aplicado" en la landing que en realidad no
   se aplicará en el checkout, sin ningún mensaje que lo alerte — es el tipo de
   fallo silencioso que pide revisar esta auditoría.
3. **[Cosmético] Enlaces de redes sociales sin destino.** Los tres íconos de
   redes sociales del footer (Instagram, X, LinkedIn — líneas 321-323) usan
   `href="#"` sin URL real. Los otros `href="#"` del archivo (líneas 66, 308)
   son intencionales: abren el modal gratuito vía JS (`js-open-free`), no son
   enlaces rotos.
4. **CNAME correcto:** contiene únicamente `alas7.com` (no hay rastro de
   `vitanews` ni dominios viejos). Sin hallazgos.
5. **Sintaxis JS:** el único bloque `<script>` (líneas 386-538) pasa
   `node --check` sin errores.
6. **Sin referencias a `alas7.mx` ni otros dominios inexistentes** en el HTML.
